# RealClima

Aplicativo de previsão do tempo com consenso meteorológico multi-modelo (ECMWF IFS, NOAA GFS, DWD ICON, CMC GEM), interface viva (*Living Sky*) e widget nativo para Android.

## Recursos
- **Consenso Multi-Modelo**: Compara previsões dos principais modelos meteorológicos mundiais.
- **Living Sky Interface**: Céu dinâmico e atmosférico que reflete as condições climáticas e horários em tempo real.
- **Widget Nativo Android**: Widget horário moderno com previsão hora a hora e temperatura atual.
- **Suporte Mobile e Desktop**: Interface fluida e responsiva com suporte a Live Reload para desenvolvimento no dispositivo.
